## Step-by-Step Pengerjaan

### 1. Buka Repository Target

Repository:

```text
https://github.com/s3condnyah3rwthme/portofolio
```

Perhatikan isi branch utama atau `main`.

---

### 2. Cek README pada Branch Main

Baca file `README.md`.

Perhatikan bagian:

* Alternative Branches
* Open Issues
* Releases
* Archive

Jika menemukan kalimat:

```text
Some things are not where they seem. Look deeper.
```

berarti peserta harus mengecek bagian selain branch utama.

---

### 3. Cek Daftar Branch

Cari branch selain `main`, misalnya:

```text
jalanjalan-notes
blog-content
wifi-tools
akuadalah-branch-1
akuadalah-branch-2
```

Branch dummy dapat diabaikan jika hanya berisi file dummy.

---

### 4. Cek Branch `jalanjalan-notes`

Masuk ke branch:

```text
jalanjalan-notes
```

Cari informasi seperti:

```text
username
event
lokasi
tahun
```

Catat seluruh petunjuk yang ditemukan.

---

### 5. Cek Branch `blog-content`

Masuk ke branch:

```text
blog-content
```

Periksa folder:

```text
_posts/
assets/
```

Buka file post yang tersedia.

Cari petunjuk seperti:

```text
Cyber Summit 2026
Jakarta
OMI
PNJ-Hotspot
```

---

### 6. Cek Branch `wifi-tools`

Masuk ke branch:

```text
wifi-tools
```

Periksa file:

```text
.github/ISSUE_TEMPLATE/connection-issue.md
RELEASES/v0.1.0-conference-photos.md
```

Cari petunjuk seperti:

```text
PNJ-Hotspot
OMIPNJ
Cyber Summit 2026
conference_photos.zip
```

---

### 7. Cek Tab Issues

Buka tab:

```text
Issues
```

Cari issue:

```text
Connection issue with EspressoCafe network
```

Catat informasi penting seperti:

```text
PNJ-H0tspot
Cyber Summit 2026
OM1PNJ
```

---

### 8. Cek Tab Releases

Buka tab:

```text
Releases
```

Cari release:

```text
v0.1.0
conference_photos.zip
```

Jika terdapat file ZIP, unduh dan periksa isinya.

Jika tidak ada, abaikan.

---

### 9. Susun Flag

Dari hasil investigasi peserta akan mendapatkan:

```text
PNJ-H0tspot
OM1PNJ
2026
```

Susun sesuai format:

```text
ITECHNO26{LANpnj_Tempatpnj_Tahun}
```

---
