# Git Happens

Selama proses pengembangan sebuah repository GitHub, seorang developer sering kali meninggalkan berbagai artefak digital seperti commit lama, branch yang terlupakan, issue, release notes, maupun file yang sudah tidak lagi digunakan.

Repository berikut diduga menyimpan informasi yang tidak sengaja tertinggal selama proses pengembangan. Lakukan investigasi menyeluruh terhadap seluruh komponen repository dan temukan flag yang tersembunyi.

Repository yang terlihat sederhana belum tentu menyimpan seluruh ceritanya pada branch utama.
